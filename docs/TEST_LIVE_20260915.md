## BUG-1 (🔴 CHẶN) — MASTER_DATA đọc ra rỗng toàn bộ cột định danh (lỗi DỮ LIỆU/sheet, không phải code)

**Hiện tượng:** `action=list` trả **19 record nhưng mọi trường rỗng** (`UseCase_ID/UseCase_Name/Team/Current_Stage/Owner_*/Status/Workflow/Pain_Point…` đều undefined/''); US mới AIUS-0001 vừa tạo cũng không xuất hiện (`owner_login=tuantt4` → 0 kết quả). Kéo theo hỏng: **Cập nhật US (picker trống), Use Case của tôi, Dashboard, Thư viện, Leaderboard**.

**Truy vết (đã loại trừ code):**
- `Code.gs`: `action=list` → `listUseCases_()` (đúng).
- `listUseCases_` mapper repo emit đủ `usecase_id/name/team/stage`; live trả schema = repo **trừ đúng các key không có fallback `|| ''`** (bị `undefined` nên JSON bỏ key) + có key mới `owner_display/usecase_category` → **live đang chạy đúng bản code repo mới nhất**.
- `readSheetAsObjects_` (Utils.gs) map theo **header thật ở dòng 1** của sheet; đã lọc bỏ dòng rỗng → 19 record là dòng CÓ data, nhưng key không khớp tên cột code cần.
- **Đối chứng quyết định:** `listUseCasesH1_` dùng **cùng** `readSheetAsObjects_` đọc sheet `Data H1` → trả **297 record đầy đủ** mọi trường. Cùng code, khác sheet → **gốc lỗi 100% ở sheet MASTER_DATA**.

**Kết luận:** dòng **header của sheet `MASTER_DATA`** trên spreadsheet live **không khớp** tên cột trong `Config.gs` HEADERS (bị đổi tên / chèn dòng trống phía trên / lệch dòng).

**Cách sửa (việc [TT], trên Google Sheet — KHÔNG sửa code):**
1. Mở spreadsheet `1xLMQLTgj2sRf1l9C6s6AHCT5zWJLQOofL375t8Pv_NA`, tab `MASTER_DATA`.
2. Kiểm **dòng 1** phải đúng tên cột như `Config.gs` HEADERS (đặc biệt `UseCase_ID, UseCase_Name, Owner_Name, Owner_Email, Team, Status, Current_Stage, Record_ID, Business_Category, Submit_Date, Created_At`). So với tab `Data H1` (đang đúng) để đối chiếu.
3. Nếu có dòng trống chèn phía trên header → xóa. Nếu header bị đổi tên → đặt lại đúng.
4. Sau khi sửa header, `ensureSheetColumns_` sẽ tự thêm cột thiếu khi ghi; hard-refresh dashboard nghiệm thu picker "Cập nhật US" hiện danh sách US thật.

## BUG-2 (🟠 đã VÁ) — Xóa Bài tập AI không có hiệu lực (ép kiểu boolean Sheets)

**Hiện tượng:** `exercise-delete` trả 200 (`{deleted:true}`) nhưng bài **vẫn xuất hiện** trong `exercise-list`.

**Gốc rễ (code):** `deleteExercise_` ghi `Active:'FALSE'` → `setValues(['FALSE'])` → **Google Sheets tự ép chuỗi 'FALSE' thành boolean FALSE**. Khi đọc lại `getValues()` trả boolean `false` → `listExercises_` lọc `String(r.Active) !== 'FALSE'` → `String(false)`='false' ≠ 'FALSE' → **không loại** → item vẫn hiện. (Playwright mock trả chuỗi 'FALSE' nên không bắt được.)

**Đã vá** `assets/gas-backend/ExerciseService.gs:57`:
```js
// trước
var out = all.filter(function (r) { return String(r.Active) !== 'FALSE'; });
// sau (khớp convention sẵn có LookupService/AuthTokenService)
var out = all.filter(function (r) { return r.Active !== false && String(r.Active).toUpperCase() !== 'FALSE'; });
```
- Quét toàn backend: mọi chỗ khác đã phòng thủ đúng (`String(x).toUpperCase()`), đây là điểm sót duy nhất.
- **Cần [TT] redeploy GAS** (dán lại `ExerciseService.gs`) mới hiệu lực live.

**Ghi nhận (latent, chưa vá — luồng ngủ):** `AdminService.gs:512` `stage_changed: row.Stage_Changed === 'TRUE'` thiếu `|| === true` như các dòng lân cận (524/529/576/626). Milestone infra hiện "ngủ" (TD-CR-02) nên không lộ; nên đồng bộ khi động vào milestone.
